# 通用文案规则（综合 InsightCut 旁白规则和 Pixelle-Video 话题旁白规则）
1. **给 TTS 读的口语稿**：每镜 1–3 句，句子短，不用书面语，不堆形容词；不要出现网址、emoji、序号和括号注释。
2. **标点就是停顿**：句中用中文标点（，。？！……：“”）控制语气和停顿，比如“对吗？错。”中间要停一下、语调要变；每镜最后一句也要以句号、问号或感叹号结尾。
3. **开头 3 秒定生死**：【引导语】不超过 20 个字，必须是反常识、扎心、悬念、提问中的一种，不能是“大家好”“今天我们来聊聊”。
4. **开头不许套路化**：同一个词（比如“其实”“你有没有”“想象一下”“很多人”）在所有分镜里最多只能当一次开头；不要形成“第 N 句总是以 X 开头”的规律。
5. **叙事结构**：吸引注意 → 提出观点 → 展开解释或举例 → 给启发或可执行的小动作；最后一镜引导评论或关注，但不要硬广。
6. **事实可靠**：可以引用研究、书籍、人物原话，但**不许编造出处、数据和名人名言**；拿不准的就用“有研究发现”这类说法，或者干脆不写。
7. **合规**：不涉及医疗诊断、投资建议、政治、色情、暴力；不贬低任何群体；不用“最”“第一”“100%”这类绝对化用语。
8. 写完自查：总字数达标、引导语不超过 20 字、没有重复的开头词。

# 冷知识赛道专属要求
- **选题范围**：生活常识的反面（比如“香蕉其实是浆果，草莓不是”）、身体奥秘、动物冷知识、历史上的巧合、物品设计背后的原因、汉字和词语的来源。
- **引导语公式**（任选一种，不要照抄）：
  - 反常识：“你每天都在用的XX，其实一直用错了”
  - 数字冲击：“人一生中，有X年在做这件事”
  - 悬念：“为什么XX都是这个形状？答案很意外”
- **结构**：第1镜抛出结论 → 第2–3镜讲“为什么” → 中间几镜每镜补一个具体细节或数据 → 倒数第2镜再加一个相关冷知识当彩蛋 → 最后一镜问观众：“你还知道哪些？评论区告诉我”。
- **信息密度**：每镜只讲一个信息点，必须具体（年份、数字、名字），禁止“很久很久以前”“科学家发现了一些东西”这类空话。
- **事实核验**：只用被广泛证实的说法；有争议的要说“有一种说法是”。
- 画面要把这一镜的知识点画出来（比如讲蜂鸟心跳，就画一只停在花前的毛毡蜂鸟，旁边是放大的心形）。

# 通用生图规则
- 每一镜一张图。提示词用即梦（中文）写，结构是：**[风格前缀]，[本镜画面主体和动作]，[场景/道具]，[构图]，[比例]**。
- 风格前缀**每一张都要原样带上**，不许中途换风格：
  「毛毡手工艺风格插画，羊毛毡质感，可爱扁平造型，柔软触感表面，温暖马卡龙色调，微缩场景模型感，高调明亮画面，主体居中清晰，背景简洁，无文字」
- 这是不露脸账号：画面里不出现真人正脸，人物只能是背影、剪影、手部特写或卡通形象。
- 画面里不要出现文字、字幕、水印和 logo（字幕由剪映加）。
- 画面要具体可画：写“一只猫趴在键盘上睡着，屏幕亮着”，不要写“打工的疲惫感”这种抽象说法。
- 比例 9:16，主体放在画面中部，上下各留一些空间给标题和字幕。
