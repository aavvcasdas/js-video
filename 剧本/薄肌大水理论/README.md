每个赛道的文件夹里有 3 个文件：

| 文件 | 用途 |
|---|---|
| `口播文案_图片序号_对应表.txt` | **auto-catvideo 直接用**：复制到 `auto-catvideo/剧本/`。只有 3 列，开头 `#` 行是注释（含引导语、建议音色），auto-catvideo 会跳过 |
| `分镜提示词.txt` | 每镜一条即梦提示词，已带赛道风格前缀和比例（打工人猫还带固定橘猫角色锚定句），复制即用 |
| `AI回复.txt` | js-video 格式（含标题、封面文案、第 4 列标签、评论区置顶），可以粘贴到 `jobs/…/02_AI回复.txt` 后 `python new_job.py --parse` |

### 用 auto-catvideo 生成

1. 把 `口播文案_图片序号_对应表.txt` 复制到 `auto-catvideo/剧本/`（覆盖同名文件）。
2. 按 `分镜提示词.txt` 出图，存为 `auto-catvideo/image/shot_01.jpg …`。
3. 把 `create_video_final.py` 里的 `lead_text = "…"` 改成对照表第 2 行注释里的引导语（auto-catvideo 的引导语是写死在代码里的）。
4. 可选：把 `VOICE_SPEAKER` 换成注释里的建议音色。
5. 运行 `python create_video_final.py`。

注意：auto-catvideo 原本是横屏 16:9（人生副本），这里的提示词按竖屏出图（心理学 1:1、书单 3:4）。如果继续用横屏，把提示词末尾的比例改成 16:9。
第 4 列标签（语录出处、书单书名、打工猫时间戳）只在 js-video 里显示。auto-catvideo 会把它当口播读出来，所以 auto-catvideo 用的对照表里已经去掉了。
语录和书单如果需要显示出处或书名，在剪映里手动加文字，或者用 js-video 生成。

## 发布前请核实

- **语录出处**：《道德经》第八章「上善若水」，《庄子·山木》「君子之交淡若水」，《庄子·逍遥游》「偃鼠饮河，不过满腹」，《论语·述而》「饭疏食饮水，曲肱而枕之」，《黄帝内经·素问·上古天真论》「食饮有节，起居有常，不妄作劳」，毛泽东《体育之研究》（1917）「文明其精神，野蛮其体魄」，苏轼《浣溪沙·细雨斜风作晓寒》「人间有味是清欢」，村上春树「Pain is inevitable. Suffering is optional.」（中译本措辞略有不同，以你手上的译本为准）。
- **冷知识数据**：肾脏每小时约排 0.8–1 升水是常见科普说法；2007 年美国加州电台「Hold Your Wee for a Wii」比赛，当事人约喝下 7.5 升水后死于水中毒。
- **心理学实验**：Langer & Rodin（1976）养老院实验，实验组除了照顾植物还被给予更多自主选择；剧本做了简化。
- **自律实验**：Thorndike 等人（2012）在麻省总医院食堂做的选择架构研究，3 个月内汽水销量约降 11.4%、瓶装水约升 25.8%，《掌控习惯》第 6 章引用。
- **书单**：《掌控习惯》（詹姆斯·克利尔）、《我们为什么要睡觉？》（马修·沃克）、《运动改造大脑》（约翰·瑞迪）、《当我谈跑步时我谈些什么》（村上春树）。引用的金句以你手上版本的原文为准。
