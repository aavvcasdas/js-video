# 潮汐 · Clawd MV

用 [PDoomVideo](https://github.com/JohnHeibel/PDoomVideo) 的整套手绘画布（p5.js + p5.brush + Clawd）给《潮汐》做的 MV。

- 歌曲：`潮汐.MP3`（31.84 s，118 BPM，第一拍 ≈ 0.05 s）
- 成片：`潮汐_MV.mp4`（1920×1080，20 fps，立体声 AAC）
- 画面：PDoomVideo 原版的九个章节、Clawd / Researcher / 观众席、笔触转场、水彩纸纹，全部原样保留
- 卡点：所有镜头切换都落在 118 BPM 的拍点上，见下面的对照表

## 怎么做的

原片是按 88 BPM 编排的 156.6 秒动画。这里没有重画场景，而是把**影片时钟重新映射**到《潮汐》的 118 BPM 上：

```
影片时间 = 0.21 + 影片拍号 × 0.6818      （原片 88 BPM 的拍 = 0.6818 s）
歌曲时间 = 0.05 + 歌曲拍号 × 0.5085      （潮汐 118 BPM 的拍 = 0.5085 s）
```

`src/remap.js` 里是一张 `[歌曲拍号, 影片拍号]` 的对照表。每一段里影片以 118/88 ≈ 1.34 倍速播放（正好一个影片拍 = 一个歌曲拍），所以原动画里所有踩拍的动作——Clawd 的弹跳、水花、翻页、幕布——都会落在《潮汐》的拍子上；每次换镜头也都在歌曲的整拍上。起点 0–2.08 s 是唯一的例外：标题镜头放慢到 0.63×，让「潮汐」在开场站满两秒，2.08 s 的第一句歌词处再切走。

## 渲染

需要 Node.js、Chrome（或 Chromium）和 ffmpeg。

```bash
npm install

# 1) 逐帧绘制（可断点续渲）
node render.mjs --frames=0:31.84 --fps=20 --workers=2
#    没有 GPU 时可以加 --scale=0.35（先按 35% 分辨率绘制，合成时再放大）

# 2) 合成 MP4（画面 + 潮汐.MP3）
node render.mjs --encode --out=潮汐_MV.mp4 --fps=20

# 快速检查某一帧 / 一格分镜
node render.mjs --stills=16.6,23.0 --out=out/stills
node render.mjs --sheet=0.5,4.1,8.2,12.3,16.3,22.4,28.5,30.9 --cols=4 --w=480 --out=out/sheet.jpg
```

Chrome 不在默认路径时用 `--chrome=/path/to/chrome` 指定（Linux 下也可以设 `CHROME_PATH` 环境变量）。

> 说明：这台沙箱只有软件 WebGL，全片是 `--scale=0.35` 渲染再放大合成的；本机有 GPU 时去掉 `--scale` 即可出原生 1080p。

|---|---|

| `src/lyrics.js` | 《潮汐》歌词与时间 |
| `src/timeline.js` | 章节注册、笔迹转场、字幕、潮汐表 |
| `src/ch/*.js` | 原片九个章节（只改了标题与表盘文字） |

| `render.mjs` | 逐帧渲染 + MP4 合成 |
