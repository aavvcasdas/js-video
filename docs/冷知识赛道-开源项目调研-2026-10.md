这样「打工人猫meme / 名人语录 / 自律 / 心理学干货 / 书单」都能用同一个脚本跑，只换 prompt 和风格模板就行。

## 5. 怎么落到 auto-catvideo 上

你现在的结构：`分镜提示词.txt` → `image/shot_XX.jpg` → `tts_grouping.py` → `create_video_final*.py`（JyProject + 蒙版/九宫格/快闪开头）→ 剪映草稿。

1. **多赛道模板化**：把 `分镜提示词.txt` 拆成按赛道分的 prompt 预设，比如 `prompts/冷知识.txt`、`心理学干货.txt`、`名人语录.txt`、`自律打卡.txt`、`书单.txt`、`打工人猫meme.txt`。
   文案结构可以参考 InsightCut 的「文案风格」和 Pixelle-Video 的模板；书单参考 whiteboard-book-video 的 `references/script-writing.md`。
2. **升级 pyJianYingDraft**：skill 里 vendor 的 `scripts/vendor/pyJianYingDraft` 被你手动加过蒙版关键帧。
   上游 0.3.1 修了新版剪映的蒙版导出（`materials.common_mask`），要先 diff 一下再合并，别把你自己加的 `KP.mask_*` 冲掉。
3. **合并 skill 的修复 PR**：jianying-editor-skill 那几个「静默产出错误成片」「GBK emoji」相关的 PR 还没进主干，可以手动 cherry-pick。
4. **动态感**：「AI 动态图片滚动」用图片关键帧（缩放 + 平移，也就是 Ken Burns）就够了，你的脚本里已经有 KeyframeProperty；要更动一点再接图生视频（Pixelle-Video 支持 Seedance/Kling/WAN）。

## 6. 提醒

- 「5 分钟一条、广告单价高、零试错」是带货话术。这类图文 / AI 配图号**同质化很严重**，真正决定结果的是选题和前 3 秒钩子，工具只能解决产能问题。
- 抖音、视频号、小红书都要求 **AI 生成内容主动打标**，没标会被限流；名人语录要核实出处（伪造语录很容易被举报），书单号注意封面版权。
- AGPL 项目（MoneyPrinterV2、OpenMontage、ArcReel、short-video-factory）只自己用没问题；改完拿去做对外服务的话，要开源修改后的代码。
